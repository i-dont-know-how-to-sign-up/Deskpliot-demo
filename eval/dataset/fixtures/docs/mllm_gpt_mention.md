# Multimodal Model Survey Note

This note surveys multimodal large language models. GPT-4V is mentioned as one representative system, but this document does not describe the architecture, training process, or workflow of the GPT model family.

## General MLLM Architecture

A generic multimodal system can contain a modality encoder, an adapter, and a language model. This is a survey-level abstraction and must not be presented as GPT's specific workflow.
