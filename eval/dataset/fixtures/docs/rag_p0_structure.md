# Atlas 存储客户端

## 核心目标

Atlas 的核心目标是提供可恢复的分片上传，并保证断点续传后块校验一致。
客户端使用 SHA-256 校验每个分片，错误码为 ATLAS-409。

## 性能约束

单个分片默认大小为 8 MiB。并发上传默认四路，弱网环境下降为两路。

## 故障恢复

服务端返回 ATLAS-503 时，客户端采用指数退避，最多重试三次。
恢复记录保存在本地 checkpoint 中，上传完成后删除。

## 参数表

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| chunk_size | 8 MiB | 上传分片大小 |
| max_retries | 3 | 最大重试次数 |
