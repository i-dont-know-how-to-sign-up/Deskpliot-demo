DeskPilot 系统架构

个人办公 Agent · 请求流向与横切能力

CURRENT IMPLEMENTATION · 2026-10
01 / ENTRY

桌面交互层

PySide6 · Qt Quick / QML
聊天与流式输出问题、回答、Steps、引用证据
会话与附件历史记录、图片预览、拖拽与粘贴
审批与任务面板一次性 action_id；暂停、取消、恢复和节点状态
02 / STATE

Agent 核心与上下文工程

DocumentQAAgent · ContextBuilder
统一任务入口创建会话、接收问题与附件、记录运行步骤和模型用量
上下文构建当前问题 + 最近对话 + 摘要 + 检索记忆；按角色与 token 预算选择
工具摘要与有界索引候选进入路由
03 / DECIDE

意图识别与执行路径

IntentRouter · Jev · SlotValidator

可选 Jev 前置门控 · off / shadow / gated；仅高置信、无副作用直答可跳过原 Router，异常时回退。

FAST PATH / DIRECT
直接回答无需外部资料或动作；同次路由调用可返回正文→ 最终结果
FAST PATH / TOOL
单工具调用选择注册工具、校验槽位、执行一次独立动作→ 工具注册表
COMPLEX PATH / PLAN
依赖任务编排查资料、生成内容、写文件或发送邮件等多步骤任务
Planner PlanRepair Supervisor
单工具与多步骤任务进入受控工具层
04 / EXECUTE

Agent Loop 与工具

PlanExecutor · Supervisor · TaskService
计划与多 AgentKnowledge 获取证据 → Communication 生成产物；按依赖推进、观察结果
任务 HarnessSQLite 状态 / attempt / 检查点；预算、lease/CAS、分类重试与恢复
工具注册表Web · 文件/桌面 · Shell/Python · 邮件 MCP · 知识库 · 视觉/记忆
05 / CAPABILITY

领域能力层

按需调用，不是每轮必经
文档 RAG解析 → 结构/语义分块 → BM25 + Dense → RRF / 精排 → 可选 Jev 证据门控 → 扩展与 MMR → 引用回答
Sentence WindowParent可选 Cross Encoder
记忆系统会话消息 → 抽取 Gate → 事实/偏好/任务 → 向量召回；视觉事实带资产引用，pending 审批后生效
滚动摘要TTL / supersede视觉预算
多模态图片校验与去重 → OCR / 视觉向量 → 多路检索 → VLM 图文问答；图片引用可进入视觉记忆
PaddleOCRSigLIP2 可选Qwen-VL API
06 / FOUNDATION

模型与存储基础

模型服务OpenAI-compatible LLM / Embedding / VLM；可选 OpenRouter Jev；本地 OCR 与视觉编码器按需加载
本地数据SQLite / FTS5、文档与记忆索引、SHA-256 图片资产、会话 JSONL、任务及副作用日志
生成回答、来源与 Steps；必要时抽取记忆并回到桌面端
07 / OUTPUT

结果与反馈

可核对的结果答案、产物及邮件结果、来源引用、Steps、失败与人工接管状态
持续会话状态会话历史、压缩摘要、有效长期记忆及视觉资产引用

权限与安全

在具体工具执行路径上检查风险。

  • 路径和覆盖/移动风险分级
  • 命令白名单、Python AST 拦截
  • 敏感图片上云确认
  • 一次性、会话绑定的 action_id
  • 副作用日志；unknown 禁止自动重放
  • 受控文件补偿与邮件副本核对

测评与观测

覆盖入口、领域能力与最终结果。

  • pytest 确定性回归
  • DeskPilotBench 离线 / API 用例
  • 多模态专项用例
  • Jev off / gated 对照与证据评分
  • 故障注入与检查点复用
  • 分模块正确率、延迟、Token
  • 版本化基线与 API 预检

工程优化

降低桌面端启动和重型模型成本。

  • 模型延迟加载、worker 隔离
  • 图片与向量幂等缓存
  • OCR / 向量批处理
  • SQLite WAL 与 busy timeout
  • 失败通道独立降级；单机恢复

阅读方式：主列自上而下表示任务处理；右列是横切能力。直接回答跳过工具，复杂任务才进入 Planner；Jev 与视觉模型按配置启用。任务恢复仅为单机机制，文件补偿与邮件核对均不构成通用回滚或 exactly-once；Reflection 尚未形成完整自动闭环。
